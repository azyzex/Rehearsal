# Preview a migration

Open a `.sql` migration and press `ctrl + alt + d` (`cmd + alt + d` on a Mac), or use the button in the editor's title bar.

Each statement gets a row with its consequence as a number: how many rows it changes or removes, what it cascades to, which lock it takes, and whether it will fail.

The same verdicts appear above each statement in the file, and in the Problems view.
